Select the model's parts in the 3D view and the Scene tree (with an Explode button that replaces the `openscad.enableLazyUnion` setting), clearer Measure tool (dimension arrows, snapping to sharp edges, Escape to leave), Settings button in the toolbar, Accordion / Expand all / Collapse all buttons for parameter groups, dedicated editors for color, file, folder and font text parameters, a default model color (`openscad.defaultColor`), automatic Manifold backend when OpenSCAD supports it (`openscad.renderBackend`), detection of OpenSCAD nightly builds on Windows, and automatic preview paused by default.

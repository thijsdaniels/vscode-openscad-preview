Colour icons with relief across the preview: Fluent UI System Icons (MIT) where they fit, hand-drawn isometric icons for 3D concepts (render modes, snapping, model parts, cross-section…). Icons are generated with `npm run icons` from `scripts/generate-icons.ts`; `scripts/icon-sheet.ts` writes an HTML sheet of all of them for review.
